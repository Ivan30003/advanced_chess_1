# Advanced Chess — продвинутые шахматы

Advanced Chess — desktop-игра на Python и pygame. Проект развивается
поэтапно; на текущем этапе реализованы полноценные стандартные шахматы на
доске 8×8 в режиме hot-seat: два игрока по очереди играют за одним
компьютером.

Порталы, благословения короля, доски 6×6 и 10×10, а также специальные
способности намеренно не реализованы — это механики следующих этапов.

## Установка

Требуется Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Окно по умолчанию имеет размер 1280×860, минимальный размер — 1024×720.
Окно можно свободно изменять в размерах, доска и боковая панель
подстраиваются. Частота обновления — 60 FPS.

## Управление

Партия управляется только мышью, без drag-and-drop.

- **Левый клик по своей фигуре** — выбрать её. Подсвечиваются клетка фигуры и
  легальные ходы: точки для пустых клеток, кольца для взятий.
- **Левый клик по легальной клетке** — выполнить ход.
- **Клик по другой своей фигуре** — переключить выбор.
- **Клик по пустой или нелегальной клетке** — снять выбор.
- **Правый клик или Esc** — снять выбор.
- **Наведение на вражескую фигуру**, которую можно взять выбранной фигурой,
  включает пульсирующее красное свечение и утолщённую красную рамку.
- **Превращение пешки** — модальное окно с выбором Q, R, B или N. Отмена
  невозможна: превращение нужно завершить выбором фигуры.
- **Колесо мыши над журналом** — прокрутка списка ходов.
- **Esc в меню** — диалог подтверждения выхода.
- **Esc в настройке** — возврат в главное меню.
- **Esc на экране правил** — возврат на предыдущий экран.

На игровом экране доступны кнопки «Новая партия», «Правила» и «В меню».
После мата или пата ввод блокируется, а на экране результата остаются
кнопки «Новая партия» и «В меню».

## Правила 8×8

- Белые всегда снизу, файлы `a`–`h`, ранги `1`–`8`, клетка `a1` тёмная.
- Стандартная начальная расстановка: `R N B Q K B N R` на первом ранге,
  пешки на втором и седьмом рангах, чёрные фигуры зеркально на восьмом.
- Ходы всех фигур соответствуют классическим шахматам.
- **Рокировка** — короткая и длинная для обеих сторон. Требуются права
  рокировки, свободные клетки между королём и ладьёй, отсутствие шаха и
  атаки на клетки, через которые проходит король.
- **Взятие на проходе** — доступно только сразу после двойного хода пешки.
- **Превращение** — на последнем ранге в ферзя, ладью, слона или коня.
- **Шах** подсвечивается красным на клетке короля.
- **Мат** — шах и отсутствие легальных ходов; партия завершается победой
  противоположной стороны.
- **Пат** — нет легальных ходов, но шаха нет; ничья.
- Ход, оставляющий собственного короля под шахом, невозможен.

Ничьи по правилу 50 ходов, троекратному повторению и недостаточному
материалу отложены до следующего этапа. Сдача и ничья по соглашению также
появятся позже.

## Настройка партии

В рамках второго этапа экран настройки ограничен:

- доступен только размер доски **8×8**;
- количество порталов зафиксировано на **0**;
- способности короля выключены;
- можно включить или отключить **подсказки легальных ходов** (по умолчанию
  включены).

Недоступные варианты показаны, но заблокированы, чтобы обозначить будущие
этапы.

## Журнал ходов

Боковая панель показывает:

- индикатор «Ход белых» / «Ход чёрных»;
- номер хода;
- предупреждение «шах!»;
- базовый журнал в упрощённой координатной нотации: `e2-e4`, `e4xd5`,
  `O-O`, `O-O-O`, `e7-e8=Q`.

После завершения партии в журнале сохраняется полная запись, а на экране
результата выводится причина: мат или пат.

  ui/

    theme.py                палитра, шрифты, отступы и функции отрисовки
    piece_art.py            векторные фигуры и иконки способностей
    board_view.py           доска, координаты, подсветки и свечение
    widgets.py              кнопки, переключатели, карточки, диалоги, прокрутка
    setup_config.py         dataclass SetupConfig и ограничения этапа
    scenes/
      __init__.py
      menu.py               главное меню
      setup.py              экран настройки партии
      game.py               игровой экран, журнал, превращение, результат

Пакет `chess/core` не импортирует pygame. Интерфейс только отображает
состояние и передаёт действия, а вся проверка легальности выполняется в ядре.

## Тесты

Тесты работают без реального дисплея: драйвер SDL выставляется в `dummy` до
импорта pygame.

```bash
pytest -q
```

Проверяются:

- perft от начальной позиции 8×8 на глубину 1–4:
  `20`, `400`, `8902`, `197281`;
- perft позиции Kiwipete с рокировкой и позиции с взятием на проходе;
- рокировка (включая запрет под шахом и через атакованную клетку, потерю
  прав);
- взятие на проходе и его истечение через ход;
- превращение во все четыре фигуры;
- шах, мат, пат и запрет хода, оставляющего короля под шахом;
- отрисовка всех сцен, клики выбора/хода, модальное превращение, блокировка
  ввода после результата, ресайз до минимального окна;
- отсутствие импортов pygame в `chess/core`.

## Примечания

- Вся графика рисуется примитивами pygame. Внешних PNG, SVG, шрифтов и звуков
  нет. Используются системные шрифты с поддержкой кириллицы: DejaVu Sans,
  Noto Sans, Liberation Sans, Arial, с запасным вариантом `pygame.font.Font(None)`.
- Идентификаторы кода — на английском, все тексты интерфейса — на русском.
- `BlessingType` и описания способностей оставлены в `chess/core/pieces.py`,
  чтобы будущие этапы использовали те же чистые типы.
- `GameState.apply_turn(..., detect_result=False, record_history=False)`
  используется perft-тестами, чтобы не выполнять лишнюю работу на каждом
  узле перебора.
- Механики следующих этапов (порталы, благословения, доски других размеров,
  полные ничьи) намеренно не реализованы.
