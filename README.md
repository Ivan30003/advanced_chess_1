# Advanced Chess — продвинутые шахматы

Продвинутые шахматы на Python и pygame с доской 6×6, 8×8 или 10×10,
порталами и способностями короля. Игра рассчитана на двух игроков за одним
компьютером (hot-seat).

Проект развивается поэтапно. На текущем этапе реализован каркас приложения,
визуальная тема, векторные фигуры, главное меню, экран настройки партии и
заглушки игрового экрана и правил. Игровая логика ещё не реализована.

## Установка

Требуется Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Окно по умолчанию имеет размер 1280×860, минимальный размер — 1024×720.
Окно можно свободно изменять в размерах, интерфейс подстраивается под него.
Частота обновления — 60 FPS.

## Управление

- **Мышь** — выбор кнопок, карточек способностей, размеров доски и числа порталов.
- **Esc в меню** — открывает диалог подтверждения выхода.
- **Esc в настройке** — возвращает в главное меню.
- **Esc на игровом экране и экране правил** — возвращает на предыдущий экран.
- **Колесо мыши, ↑/↓, PageUp/PageDown, Home/End** — прокрутка текста правил.

Навигация: меню → настройка партии → заглушка игры → назад в настройки или меню;
меню → правила → назад.

## Настройка партии

Перед партией можно выбрать:

- размер доски: 6×6, 8×8 или 10×10;
- количество пар порталов: 0–3;
- включены ли способности короля;
- по одной способности для белых и чёрных из пяти вариантов:
  неуязвимость, двойной ход, возрождение, заморозка и проход сквозь фигуры.

Обе стороны могут выбрать одинаковую способность. Если способности включены и
хотя бы одна сторона не сделала выбор, кнопка «Начать партию» недоступна.
Выбранные параметры сохраняются при переходах между сценами и отображаются на
заглушке игрового экрана.

## Структура проекта

```text
main.py                     точка входа
requirements.txt            зависимости
pytest.ini                  настройка pytest
chess/
  __init__.py
  core/
    __init__.py
    pieces.py               Color, PieceType, BlessingType и описания способностей
  ui/
    __init__.py
    app.py                  окно, главный цикл и менеджер сцен
    theme.py                палитра, шрифты, отступы и функции отрисовки
    piece_art.py            векторные фигуры и иконки способностей
    board_view.py           доска, координаты, подсветки и порталы
    widgets.py              кнопки, переключатели, карточки, диалоги, прокрутка
    setup_config.py         dataclass SetupConfig и валидация
    scenes/
      __init__.py
      menu.py               главное меню
      setup.py              экран настройки партии
      game.py               заглушка игрового экрана
      rules.py              заглушка экрана правил
tests/
  test_ui_smoke.py          headless smoke-тесты
```

`chess/core` не импортирует pygame: там находятся только чистые игровые типы и
данные. Вся отрисовка сосредоточена в `chess/ui`.

## Тесты

Тесты работают без реального дисплея: драйвер SDL выставляется в `dummy` до
импорта pygame.

```bash
pytest -q
```

## Статус этапов

- **Этап 1 — выполнен.** Каркас проекта, тема, векторные фигуры, меню,
  настройка партии, заглушки игры и правил, smoke-тесты, README.
- **Этап 2 и далее — впереди.** Расстановка фигур, правила ходов, шах и мат,
  порталы, благословения, журнал ходов, полный экран правил и игровая логика.

## Примечания

- Вся графика рисуется примитивами pygame. Внешних PNG, SVG, шрифтов и звуков
  нет. Используются системные шрифты с поддержкой кириллицы: DejaVu Sans,
  Noto Sans, Liberation Sans, Arial, с запасным вариантом `pygame.font.Font(None)`.
- Для порядка в настройках добавлен отдельный модуль `chess/ui/setup_config.py`;
  это не игровая логика, а только хранение и проверка выбранных параметров.
- `BlessingType` и описания способностей находятся в `chess/core/pieces.py`,
  чтобы ядро и интерфейс использовали одни и те же чистые типы.
- Карточки способностей используют короткие подписи, чтобы помещаться в узких
  раскладках при минимальном размере окна.
- Механики следующих этапов (ходы, порталы, благословения, журнал ходов)
  намеренно не реализованы.
