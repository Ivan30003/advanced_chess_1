ADVANCED CHESS — ЕДИНЫЙ КОНТЕКСТ ПРОЕКТА
Версия контекста: 1.0
Назначение: этот файл читается перед выполнением любого этапа. Он является единственным источником истины по правилам, интерфейсу и архитектуре.

====================================================================
1. ОБЩЕЕ ОПИСАНИЕ
====================================================================

Advanced Chess — desktop-игра на Python + pygame в жанре шахмат с дополнительными механиками:

- три размера доски: 6x6, 8x8, 10x10;
- от 0 до 3 пар порталов (телепортов);
- необязательные способности короля: перед партией каждая сторона выбирает одну из пяти способностей, которой король может наделять соседние фигуры;
- режим hot-seat: два игрока играют по очереди на одном компьютере;
- русский интерфейс;
- векторная графика, без внешних ассетов;
- без ИИ, без сети, без таймера, без undo в обычной партии.

Целевая платформа: Python 3.11+, pygame 2.x, pytest.
Целевой FPS: 60.
Ориентация доски: белые всегда снизу (rank 1), файлы слева направо a..; доска не переворачивается.

Термины:
- Ход (turn) — одно действие стороны: обычный ход, двойной ход, благословение, заморозка и т.п.
- Полуход — ход одной стороны; счётчик для правила 50 ходов.
- Скользящая фигура — слон, ладья, ферзь.
- Короткая фигура — король, конь, пешка.
- Портал — пара клеток одного цвета с одинаковым символом.
- Благословение — свойство фигуры, полученное от короля.

====================================================================
2. НАСТРОЙКА ПАРТИИ
====================================================================

Экран настройки содержит:

1. Размер доски: 6x6, 8x8, 10x10 (выбор одного).
2. Количество порталов: 0, 1, 2, 3 (выбор одного).
3. Опция «Способности короля»: включена / выключена.
4. Если способности включены — выбор способности отдельно для белых и чёрных.
   - Пять карточек с иконкой, названием и кратким описанием.
   - Обе стороны могут выбрать одну и ту же способность.
   - Выбор фиксируется на всю партию.
   - В hot-seat оба выбора видны на экране (скрывать не нужно).
5. Кнопка «Начать партию». Если способности включены и хотя бы одна сторона не выбрала способность, кнопка неактивна.
6. Кнопка «Правила».
7. Кнопка «Выход».

Порталы генерируются случайно в момент старта партии, а не на экране настройки.
Для тестов и отладки генератор должен поддерживать фиксированный seed.

====================================================================
3. ДОСКА И НАЧАЛЬНАЯ РАССТАНОВКА
====================================================================

Обозначения: R — ладья, N — конь, B — слон, Q — ферзь, K — король, P — пешка. Заглавные — белые, строчные — чёрные. Пустая клетка — «.».

3.1. Доска 6x6
- Файлы a-f, ранги 1-6.
- Белые:
  - rank 1: a1=R, b1=N, c1=B, d1=Q, e1=K, f1=R;
  - rank 2: a2-f2 — шесть пешек.
- Чёрные:
  - rank 6: a6=r, b6=n, c6=b, d6=q, e6=k, f6=r;
  - rank 5: a5-f5 — шесть пешек.
- Рокировка: запрещена полностью.
- Превращение: белая пешка — на rank 6, чёрная — на rank 1.
- Взятие на проходе: белая пешка может пройти 2->4, чёрная 5->3.
- Пешек у стороны: 6.

3.2. Доска 8x8
- Файлы a-h, ранги 1-8.
- Стандартная расстановка:
  - rank 1: R N B Q K B N R;
  - rank 2: восемь пешек;
  - rank 7: восемь пешек;
  - rank 8: r n b q k b n r.
- Рокировка: стандартная, обе стороны.
- Превращение: белая пешка — на rank 8, чёрная — на rank 1.
- Взятие на проходе: 2->4 и 7->5.
- Пешек у стороны: 8.

3.3. Доска 10x10
- Файлы a-j, ранги 1-10.
- Белые:
  - rank 1: a1=., b1=R, c1=N, d1=B, e1=Q, f1=K, g1=B, h1=N, i1=R, j1=.;
  - rank 2: a2-j2 — десять пешек.
- Чёрные:
  - rank 10: a10=., b10=r, c10=n, d10=b, e10=q, f10=k, g10=b, h10=n, i10=r, j10=.;
  - rank 9: a9-j9 — десять пешек.
- Рокировка: обобщённая, обе стороны.
  - Король стоит на f1 (чёрный — f10).
  - Короткая рокировка: король f1 -> h1, ладья i1 -> g1.
    Требования: g1 и h1 пусты; f1, g1, h1 не атакованы.
  - Длинная рокировка: король f1 -> d1, ладья b1 -> e1.
    Требования: c1, d1, e1 пусты; f1, e1, d1 не атакованы.
  - Права теряются, когда король или соответствующая ладья ходит, либо ладья взята.
- Превращение: белая пешка — на rank 10, чёрная — на rank 1.
- Взятие на проходе: 2->4 и 9->7.
- Пешек у стороны: 10.

3.4. Общие правила расстановки
- Ферзь белых на d1 (6x6, 8x8) или e1 (10x10); ферзь чёрных — зеркально.
- Король белых на e1 (6x6, 8x8) или f1 (10x10); король чёрных — зеркально.
- У каждой фигуры есть id и original_square — клетка, на которой она начала партию. Для пешки, превратившейся в другую фигуру, original_square остаётся клеткой старта пешки.

====================================================================
4. СТАНДАРТНЫЕ ПРАВИЛА
====================================================================

4.1. Ходы фигур
- Пешка: на одну клетку вперёд; с начальной позиции — на две, если обе клетки свободны; бьёт по диагонали вперёд; взятие на проходе; превращение на последнем ранге.
- Конь: буквой «Г», перепрыгивает фигуры.
- Слон: по диагонали, не перепрыгивает.
- Ладья: по вертикали и горизонтали, не перепрыгивает.
- Ферзь: по вертикали, горизонтали и диагонали, не перепрыгивает.
- Король: на одну клетку в любом направлении; рокировка по правилам размера доски.

4.2. Шах, мат, пат
- Сторона не может оставить своего короля под шахом.
- Шах — король атакован хотя бы одной вражеской фигурой.
- Мат — шах и нет ни одного легального хода.
- Пат — нет ни одного легального хода, но шаха нет; ничья.
- Король никогда не «съедается»: партия заканчивается матом, а не взятием короля.

4.3. Превращение
- Игрок выбирает ферзя, ладью, слона или коня в модальном окне.
- Превращение происходит сразу после хода пешки на последний ранг.

4.4. Ничьи
- Правило 50 ходов: счётчик полуходов растёт на каждом ходу без хода пешкой и без взятия. В MVP автоматическая ничья на 100-м полуходе. Благословение, заморозка и возрождение счётчик не сбрасывают.
- Троекратное повторение: хеш состояния включает расстановку (тип, цвет, id фигуры), сторону хода, права рокировки, поле взятия на проходе, состояния благословений (тип, использовано/поглощено), кулдаун благословения, замороженные фигуры, отложенные возрождения и раскладку порталов. Третье совпадение — ничья.
- Недостаточный материал: только короли; K+B vs K; K+N vs K; K+B vs K+B с одноцветными слонами. Если есть отложенное возрождение, материал не считается недостаточным.
- Сдача и ничья по соглашению: кнопки в боковой панели. При сдаче — экран результата. При предложении ничьей — диалог «Принять / Отклонить» для второго игрока.
- Часы и undo в обычной партии отсутствуют.

4.5. Журнал ходов
- Ведётся с первого хода.
- Для обычных ходов используется упрощённая координатная нотация: e2-e4, e4xd5, O-O, O-O-O, e7-e8=Q.
- Для специальных действий нотация описана в разделе 11.

====================================================================
5. ПОРТАЛЫ
====================================================================

5.1. Создание
- Количество пар: 0..3.
- Каждая пара — две различные клетки, не занятые фигурами и не находящиеся на первом или последнем ранге.
- Клетки одной пары имеют один цвет и один символ; пары различаются цветом и символом.
- Клетка не может принадлежать двум парам.
- Порталы видны обеим сторонам с начала партии.
- Генерация случайная, с поддержкой seed для тестов.

5.2. Основные понятия
- Фигура «на портале», если её клетка — один из двух концов пары.
- Выход портала — парная клетка.
- Активация — перемещение фигуры с одной клетки пары на другую.
- За один ход допускается не более одной активации портала.
- Активация всегда необязательна.

5.3. Свободный выход в начале хода
- Если выбранная фигура в начале своего хода стоит на портале и выход свободен, игрок может бесплатно переместить её на выход, а затем выполнить обычное действие: обычный ход (включая активные способности), благословение или заморозку.
- Это перемещение не считается отдельным ходом, но считается единственной активацией портала за этот ход.
- После свободного выхода фигура не может активировать другой портал в этот же ход.
- Если выход занят любой фигурой, свободный выход невозможен; фигура может действовать обычным образом.
- Любая телепортация (свободная или в середине хода) считается перемещением фигуры: у неё выставляется has_moved=True, а у короля и ладьи теряются соответствующие права на рокировку.

5.4. Телепорт во время хода скользящей фигуры
- Слон, ладья и ферзь могут во время своего хода дойти до пустой клетки портала, телепортироваться на выход и продолжить ход.
- Выход должен быть пустым. Если выход занят любой фигурой, телепортация невозможна.
- Клетка входа должна быть пустой. Если на ней стоит вражеская фигура, это обычное взятие с завершением хода; телепортироваться в этот же ход нельзя.
- После выхода фигура может продолжить движение в любом направлении, доступном её типу (это принятое решение; см. раздел 14).
- Взятие возможно только на конечной клетке хода. Нельзя взять фигуру и продолжить движение.
- Можно остановиться на второй клетке портала, но активировать её в этот же ход нельзя.
- Можно остановиться на клетке выхода; это конец хода.
- За ход — не более одной активации, даже если на пути встретилось несколько порталов.

5.5. Короткие фигуры
- Король, конь и пешка не могут телепортироваться в середине хода.
- Если такая фигура заканчивает ход на портале, она может воспользоваться свободным выходом в начале следующего хода и затем сделать обычный ход.
- Пешка после свободного выхода ходит как пешка; двойной ход после телепортации невозможен, так как пешка уже двигалась. Взятие на проходе и превращение возможны по обычным правилам.
- Конь после свободного выхода делает обычный ход конём.
- Король после свободного выхода делает обычный ход королём.

5.6. Король и порталы
- Король не может телепортироваться на клетку, атакованную противником.
- Итоговая позиция после хода короля должна быть легальной.
- Рокировка не активирует порталы.
- После любой телепортации король считается двигавшимся и теряет оба права на рокировку; после телепортации ладьи теряется право на рокировку с этой ладьёй. Рокировка после свободного выхода невозможна.

5.7. Порталы и шах
- При проверке шаха учитываются атаки с использованием порталов: скользящая фигура может телепортироваться и взять короля; фигура на портале может свободно выйти и затем атаковать.
- Порталы не отменяют блокировку линий и обычные правила атаки.

5.8. Визуализация
- Каждая пара рисуется цветным кольцом/спиралью с символом пары.
- При наведении на портал — подсказка с координатой парной клетки.
- При выборе фигуры, которая может использовать портал, выход подсвечивается цветом пары.
- По возможности — короткая анимация исчезновения/появления при телепортации.

5.9. Нотация
- Телепорт с продолжением: a1-a4~h4-h8.
- Свободный выход и ход: b3~g6-g7.
- Если ход закончился на портале без активации, нотация обычная.

====================================================================
6. БЛАГОСЛОВЕНИЯ КОРОЛЯ
====================================================================

6.1. Общая механика
- Опция включается на экране настройки.
- Если включена, каждая сторона выбирает одну из пяти способностей до начала партии.
- Выбранная способность применяется ко всем фигурам, которые благословит этот король.
- Король может благословить дружественную фигуру на любой из 8 соседних клеток (включая диагонали).
- Нельзя благословить: себя, вражескую фигуру, уже благословлённую фигуру, фигуру, которая была благословлена ранее (даже если благословение уже израсходовано).
- Благословение заменяет ход короля: король остаётся на месте, выбранная фигура получает свойство.
- Благословение запрещено, пока король под шахом (оно не устраняет шах).
- Кулдаун: после использования на своём ходу T способность снова доступна на ходу T+3. То есть использования возможны на ходах T, T+3, T+6...
- Каждая фигура может быть благословлена не более одного раза за партию.
- Иконка благословения видна обеим сторонам.
- Кнопка благословения появляется поверх выбранного короля, если способность доступна и есть хотя бы одна допустимая цель. Если цели нет — кнопка неактивна или скрыта с подсказкой.
- После нажатия кнопки включается режим благословения: допустимые фигуры подсвечиваются золотым; клик по фигуре применяет благословение; правый клик или Esc отменяет режим.
- Благословение не сбрасывает счётчик 50 ходов (это ход без хода пешкой и без взятия).

6.2. Способность (a) — Неуязвимость (щит)
- Пассивная, одноразовая.
- При попытке врага взять благословлённую фигуру взятие отменяется.
- Атакующая фигура остаётся на клетке, где начала этот ход; благословлённая фигура остаётся на месте; благословение немедленно спадает; ход переходит другой стороне.
- Если атака была частью составного хода (двойной ход, телепорт), отменяется весь ход, а не только последний сегмент.
- Если атакующая фигура использовала двойной ход, способность двойного хода считается израсходованной.
- Взятие на проходе также отменяется.
- Если атакующий — король и после отмены он остаётся под шахом, такой ход нелегален и не предлагается.
- Иконка щита снимается.

6.3. Способность (b) — Двойной ход
- Активная, одноразовая для каждой благословлённой фигуры.
- Фигура делает два обычных хода за один ход. Второй ход начинается с клетки, где закончился первый.
- Можно взять до двух фигур (по одной за каждый ход).
- Каждый из двух ходов должен быть легальным сам по себе; итоговая позиция также должна быть легальной.
- Двойным ходом можно объявить шах, но нельзя объявить мат. Если итоговая позиция — мат, второй ход нелегален и не предлагается. Пат разрешён (ничья).
- Если пешка превращается первым ходом, второй ход делает уже превращённая фигура.
- За весь ход допускается не более одной активации портала, включая свободный выход в начале хода.
- Если взятие triggers неуязвимость и отменяет ход, двойной ход считается израсходованным.
- UI: кнопка активации, первый ход, затем режим второго хода. Отмена незавершённого двойного хода возвращает позицию к началу хода. После второго хода способность израсходована.

6.4. Способность (c) — Возрождение
- Пассивная, одноразовая.
- Когда благословлённая фигура взята, запоминается отложенное возрождение: тип фигуры на момент гибели, владелец и original_square.
- В начале следующего хода владельца, до его действия, если original_square свободна, фигура возвращается на неё.
- Если original_square занята любой фигурой, возрождение не происходит и способность теряется.
- Возвращается фигура в том типе, в котором погибла (включая ферзя после превращения), без благословения; повторно благословить её нельзя.
- Возрождение не тратит ход; владелец затем действует обычным образом.
- Возрождённая фигура может блокировать шах и может быть взята снова.
- Если партия закончилась до начала следующего хода владельца (например, матом), возрождение не происходит.
- Если original_square освободилась позже, возрождение уже не происходит.

6.5. Способность (d) — Заморозка
- Активная, одноразовая для каждой благословлённой фигуры.
- Вместо обычного хода фигура активирует заморозку.
- Все вражеские фигуры, ортогонально соседние с благословлённой (сверху, снизу, слева, справа), не могут сделать ход на следующем ходу противника.
- Заморозка действует ровно один ход противника и снимается в начале следующего хода владельца.
- Замороженные фигуры не могут: ходить, брать, делать рокировку, превращаться, телепортироваться, использовать активные способности (включая благословение и заморозку).
- Замороженные фигуры можно брать; они продолжают блокировать линии и атаковать. Их атаки учитываются для шаха и контроля клеток.
- Можно заморозить вражеского короля.
- Если ортогонально соседних вражеских фигур нет, ability нельзя активировать.
- Заморозка запрещена, пока свой король под шахом.
- UI: подтверждение использования, синий оттенок и снежинка на замороженных фигурах.

6.6. Способность (e) — Проход сквозь фигуры
- Активная, одноразовая для каждой благословлённой фигуры.
- Перед ходом игрок включает режим прохода; фигура может пройти сквозь любое количество фигур (своих и вражеских, включая вражеского короля).
- Нельзя закончить ход на своей фигуре; можно взять вражескую фигуру на конечной клетке. Не более одного взятия за ход.
- Для коня способность не даёт эффекта (он и так перепрыгивает); кнопку для коня можно не показывать.
- Пешка может пройти сквозь фигуру только при двойном ходе с начальной позиции; клетка назначения должна быть пустой.
- Можно комбинировать с порталом; за ход всё равно не более одной активации.
- Способность расходуется только если выполненный путь действительно прошёл сквозь занятую клетку. Если путь был обычным, режим сбрасывается и способность сохраняется.
- UI: переключатель, призрачный путь, индикация, что способность будет израсходована.

====================================================================
7. ВЗАИМОДЕЙСТВИЯ МЕХАНИК
====================================================================

- Неуязвимость против двойного хода/телепорта: отменяется весь составной ход; атакующий возвращается на клетку начала хода; благословение неуязвимости снимается.
- Заморозка против шаха: замороженная фигура продолжает атаковать и может давать шах; заморозка не помогает выйти из шаха.
- Возрождение против мата: если партия закончилась матом, возрождение не спасает.
- Проход сквозь фигуры + портал: можно комбинировать, но не более одной активации портала за ход.
- Двойной ход + портал: не более одной активации за весь ход, включая свободный выход.
- Свободный выход короля может предшествовать благословению; свободный выход благословлённой фигуры — заморозке.
- Благословение и заморозка не являются ходами фигуры и не активируют порталы сами по себе, но свободный выход в начале хода возможен.

- Боковая панель: чей ход, номер хода, выбранные способности, кулдаун, количество благословений, взятые фигуры, журнал ходов, кнопки «Новая партия», «В меню», «Правила», «Сдаться», «Ничья».

Правила архитектуры:
- Пакет chess.core не импортирует pygame.
- UI читает состояние и отправляет действия; вся валидация — в core.
- Состояние игры — dataclass GameState; для отмены/повторений используются снимки или клонирование.
- Ходы представлены объектами Move; составной ход — Turn (1-2 Move или специальное действие).
- Все случайные генерации принимают seed.
- Идентификаторы кода — на английском; строки интерфейса — на русском.
- Типизация, dataclasses, docstrings.

Ключевые сущности:
- Color: WHITE, BLACK.
- PieceType: PAWN, KNIGHT, BISHOP, ROOK, QUEEN, KING.
- BlessingType: INVULNERABILITY, DOUBLE_MOVE, RESURRECTION, FREEZE, PASS_THROUGH.
- Piece: id, type, color, square, original_square, has_moved, blessing, ever_blessed, frozen_until_turn.
- PortalPair: id, color, symbol, a, b.
- GameState: board, side_to_move, castling_rights, en_passant, halfmove_clock, turn_number, blessing_choice, bless_available_on, pending_resurrections, frozen, portals, history_hashes, result.
- Move: piece_id, from_square, to_square, capture, promotion, castle, en_passant, teleport_pair, pass_through, is_double.
- Turn: moves: list[Move], bless: BlessAction | None, freeze: FreezeAction | None.

Алгоритмы:
- generate_pseudo_moves(state, piece) — с учётом порталов и прохода сквозь фигуры.
- generate_legal_turns(state) — с фильтрацией по безопасности короля, кулдауну, заморозке, доступности способностей.
- apply_turn(state, turn) -> new_state.
- is_in_check(state, color) — по атакам, включая специальные механики; связанные и замороженные фигуры продолжают атаковать.
- is_checkmate, is_stalemate, detect_draw.
- Хеш состояния для повторений.
- Двойные ходы генерируются как комбинации двух ходов одной фигуры, с дедупликацией и проверкой финальной позиции; мат запрещён.
- Телепорты: не более одной активации за ход; свободный выход в начале хода; выход только на пустую клетку.
- Производительность: доска ≤100 клеток; кэш атак; ленивая генерация; логика хода — единицы миллисекунд.

- Взятие: e4xd5.

- Телепорт с продолжением: a1-a4~h4-h8.
- Свободный выход: b3~g6-g7.
- Двойной ход: Rd1-d7, d7-h7.
- Проход сквозь: Ra1-a8 (сквозь).
- Благословение: Ke1: благословение d2 (щит).
- Заморозка: Qd4: заморозка (c4, e4).
- Возрождение: Ng1: возрождение.
- Сдача: 0-1 / 1-0.
- Ничья: 1/2-1/2.

14. ПРИНЯТЫЕ РЕШЕНИЯ ПО УМОЛЧАНИЮ
====================================================================

1. Рокировка: на 6x6 запрещена; на 8x8 стандартная; на 10x10 обобщённая (король на 2 клетки к ладье, ладья — на пересечённую клетку).
2. После телепорта скользящая фигура может продолжить ход в любом доступном ей направлении, а не только по исходной линии.
3. Взятие на входном портале завершает ход; телепортироваться в этот же ход нельзя.
4. Возрождение: фигура возвращается в типе на момент гибели (включая ферзя после превращения), без благословения; повторное благословение запрещено.
5. Замороженные фигуры не могут ходить, но продолжают атаковать и давать шах.
6. Двойной ход и превращение: если пешка превратилась первым ходом, второй ход делает превращённая фигура.
7. Ничья по соглашению и сдача: кнопки в интерфейсе.
8. Звук: в MVP отсутствует.
9. Король не телепортируется на атакованную клетку.
10. Проход сквозь фигуры разрешён сквозь любые фигуры, включая вражеского короля (буквальное «любые фигуры»).
11. Правило 50 ходов: автоматическая ничья на 100-м полуходе.
12. Повторение учитывает специальные состояния (благословения, кулдаун, заморозку, отложенные возрождения, порталы).
13. Доска не переворачивается; белые всегда снизу.
14. Undo в обычной партии нет; отмена незавершённого двойного хода возвращает позицию к началу хода.
15. Подсказки легальных ходов показываются по умолчанию; в настройках можно отключить.
16. Обе стороны могут выбрать одинаковую способность; выбор виден обоим (hot-seat).
17. Активные способности (двойной ход, заморозка, проход) — одноразовые для каждой благословлённой фигуры; пассивные (неуязвимость, возрождение) срабатывают один раз.
18. Кулдаун благословения — 3 собственных хода короля; использования на T, T+3, T+6...
19. Благословение запрещено под шахом.
20. Заморозка запрещена под шахом.
21. Двойной ход: каждый под-ход легален сам по себе; итоговая позиция легальна; мат запрещён, шах разрешён; пат разрешён.
22. Неуязвимость отменяет весь составной ход атакующего и расходует его двойной ход, если тот использовался.
