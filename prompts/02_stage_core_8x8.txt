ЦЕЛЬ ЭТАПА
Играбельная партия в стандартные шахматы на 8x8: расстановка, все ходы фигур, рокировка, взятие на проходе, превращение, шах, мат, пат, ввод мышью, подсветка, красное свечение цели атаки, экран результата. Без порталов, без благословений, без досок 6x6 и 10x10.

ГРАНИЦЫ ЭТАПА
Разрешено:
- реализовывать chess/core целиком для стандартных шахмат 8x8;
- создавать board.py, coords.py, moves.py, game_state.py, rules.py, notation.py;
- расширять pieces.py;
- подключать GameScene к ядру;
- реализовывать модальное окно превращения;
- реализовывать базовый журнал ходов.

Запрещено:
- порталы;
- благословения;
- размеры 6x6 и 10x10;
- специальные способности;
- внешние ассеты;
- pygame в chess/core.

ЗАДАЧИ

1. Координаты и фигуры
chess/core/coords.py:
- Square(file: int, rank: int) или эквивалент; файлы 0..7, ранги 0..7 (белые снизу);
- преобразования в/из «e2», «a1»;
- проверка границ;
- итераторы по доске.

chess/core/pieces.py:
- Color (WHITE, BLACK), PieceType (PAWN, KNIGHT, BISHOP, ROOK, QUEEN, KING);
- Piece dataclass: id, type, color, square, original_square, has_moved;
- стабильные id для отслеживания фигур (пригодятся для благословений).
- На этом этапе blessing-поля можно не добавлять, но структура должна позволять расширение без переписывания.

2. Доска
chess/core/board.py:
- Board: хранение фигур по клеткам, доступ, установка, снятие, клонирование;
- начальная расстановка 8x8;
- удобные методы: piece_at, move_piece, remove_piece, iter_pieces, copy.
- Доска не знает о правилах ходов.

3. Ходы
chess/core/moves.py:
- Move dataclass: piece_id, from_square, to_square, capture (фигура или None), promotion, castle (None | "K" | "Q"), en_passant (bool), is_double (задел на будущее), teleport (пока None), pass_through (False).
- Turn dataclass: moves: list[Move] (на этом этапе ровно один), bless (None), freeze (None). Оставь поля для расширения.
- Вспомогательные фабрики.

4. Состояние и правила
chess/core/game_state.py:
- GameState: board, side_to_move, castling_rights, en_passant_target, halfmove_clock, turn_number, result, history;
- начальное состояние 8x8;
- клонирование;
- применение Turn/Move с обновлением прав рокировки, en passant, счётчиков, очереди хода;
- определение результата.

chess/core/rules.py:
- генерация псевдолегальных ходов для каждой фигуры;
- фильтрация ходов, оставляющих свой король под шахом;
- is_in_check(state, color);
- is_checkmate(state, color);
- is_stalemate(state, color);
- generate_legal_turns(state) для стороны, которой ходить;
- корректная рокировка: права, пустые клетки, король не под шахом, не проходит через атакованную клетку, не заканчивает под шахом;
- взятие на проходе: только сразу после двойного хода пешки, с корректным удалением пешки;
- превращение: ферзь, ладья, слон, конь; на этом этапе UI выбирает тип, ядро принимает параметр promotion;
- шах/мат/пат по стандартным правилам.

5. Базовый журнал
chess/core/notation.py:
- упрощённая координатная нотация: e2-e4, e4xd5, O-O, O-O-O, e7-e8=Q;
- функция format_turn(state_before, turn, state_after) -> str;
- журнал хранится в GameState.history как список записей.
Полный журнал со специальными механиками — этап 6; сейчас достаточно обычных ходов.

6. Игровой экран
GameScene:
- создаёт GameState для 8x8;
- BoardView рисует доску, фигуры, координаты;
- клик по своей фигуре выбирает её; клик по другой своей фигуре переключает выбор; клик по легальной клетке выполняет ход; правый клик/Esc отменяет выбор;
- подсветка выбранной фигуры;
- подсказки легальных ходов: точки для пустых клеток, кольца для взятий; подсказки можно отключить в настройках (по умолчанию включены);
- подсветка последнего хода;
- если король под шахом — красная подсветка клетки короля;
- при наведении на вражескую фигуру, которую выбранная фигура может взять, эта фигура подсвечивается пульсирующим красным свечением (обязательное требование);
- если наведение на вражескую фигуру не является легальным взятием, свечения нет;
- превращение: модальное окно с четырьмя вариантами (Q, R, B, N), выбор завершает ход; отмена не допускается после начала превращения;
- индикатор «Ход белых» / «Ход чёрных»;
- кнопки «Новая партия», «В меню»;
- экран результата: мат, пат; кнопки «Новая партия» и «В меню»;
- боковая панель с базовым журналом ходов;
- после результата ввод заблокирован.

7. Ввод и UX
- Никаких drag-and-drop: только клик-клик.
- Клик по пустой клетке без выбора ничего не делает.
- Клик по вражеской фигуре без выбора ничего не делает.
- Нелегальный ход не выполняется; выбранная фигура остаётся выбранной, если клик был по другой клетке; при клике по пустой/нелегальной клетке можно снять выбор или оставить — выбери последовательное поведение и зафиксируй.
- Esc/правый клик снимает выбор и закрывает модальные окна, кроме превращения (превращение нужно завершить).
- При ресайзе окна доска и панель корректно пересчитываются.

- Превращение выбирается через модальное окно.
- Экран результата появляется и блокирует ввод.
