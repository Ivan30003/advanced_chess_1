ЭТАП 1 — КАРКАС ПРОЕКТА, ТЕМА, ВЕКТОРНЫЕ ФИГУРЫ, МЕНЮ И НАСТРОЙКА

РОЛЬ
Ты — senior Python/pygame разработчик. Твоя задача — реализовать первый этап проекта Advanced Chess строго по единому контексту.

ПЕРЕД НАЧАЛОМ
Прочитай файл prompts/00_design_context.txt целиком. Это единственный источник истины по правилам, стилю и архитектуре. Если задание и контекст расходятся, приоритет у контекста. Если контекст что-то не уточняет — прими разумное решение и зафиксируй его в README или комментарии.

ЦЕЛЬ ЭТАПА
Создать запускаемый каркас игры и весь UI-каркас: окно, менеджер сцен, тему, векторные фигуры, главное меню, экран настройки партии, заглушку игрового экрана и заглушку экрана правил. Игровая логика на этом этапе не реализуется.

ГРАНИЦЫ ЭТАПА
Разрешено:
- создавать структуру пакетов и модулей;
- создавать enum Color и PieceType в chess/core/pieces.py;
- рисовать доску, фигуры, кнопки, карточки, подсказки;
- хранить выбранные настройки в dataclass SetupConfig;
- переходить между сценами;
- показывать выбранные параметры на заглушке игрового экрана.

Запрещено:
- реализовывать ходы фигур, шах, мат, рокировку, en passant, превращение;
- реализовывать порталы;
- реализовывать благословения;
- реализовывать журнал ходов как игровую механику;
- добавлять внешние ассеты (PNG, SVG, шрифты, звуки);
- использовать pygame внутри chess/core (кроме чистых enum в pieces.py).

ЗАДАЧИ

1. Структура проекта
Создай структуру, соответствующую разделу 10 контекста:
- main.py;
- requirements.txt (pygame>=2.5, pytest>=8);
- README.md;
- chess/__init__.py;
- chess/core/__init__.py;
- chess/core/pieces.py — только Color, PieceType и, при необходимости, вспомогательные чистые функции отображения;
- chess/ui/__init__.py;
- chess/ui/app.py;
- chess/ui/theme.py;
- chess/ui/piece_art.py;
- chess/ui/board_view.py;
- chess/ui/widgets.py;
- chess/ui/scenes/__init__.py;
- chess/ui/scenes/menu.py;
- chess/ui/scenes/setup.py;
- chess/ui/scenes/game.py;
- chess/ui/scenes/rules.py;
- tests/test_ui_smoke.py;
- tests/__init__.py при необходимости.

Не создавай пустые модули core, которые относятся к следующим этапам (board, moves, game_state, rules, portals, blessings, notation). Они появятся на своих этапах.

2. Точка входа и приложение
- main.py инициализирует pygame, создаёт окно и запускает App.
- App: экран, часы, FPS 60, обработка QUIT, ресайз окна, смена сцен.
- Базовый класс Scene с методами handle_event(event), update(dt), draw(surface).
- Сцена меню — стартовая.
- Переходы: меню -> настройка -> заглушка игры -> назад; меню -> правила -> назад.
- Окно по умолчанию 1280x860, минимальный размер 1024x720, флаг RESIZABLE.
- Заголовок окна: «Advanced Chess — продвинутые шахматы».

3. Тема
В chess/ui/theme.py:
- палитра из раздела 9 контекста;
- константы отступов, радиусов, толщин линий;
- функция get_font(size, bold=False) с подбором системного шрифта с кириллицей: DejaVu Sans, Noto Sans, Liberation Sans, Arial, fallback pygame.font.Font(None, size);
- стили кнопок: обычная, hover, active, disabled;
- функция draw_text с выравниванием;
- никаких внешних файлов шрифтов.

4. Векторные фигуры
В chess/ui/piece_art.py:
- функция render_piece(piece_type, color, size) -> pygame.Surface с кэшем;
- функция draw_piece(surface, piece_type, color, rect);
- все шесть типов: пешка, конь, слон, ладья, ферзь, король;
- оба цвета: белые (светлая заливка, тёмный контур) и чёрные (тёмная заливка, светлый контур);
- рисование только примитивами pygame.draw / pygame.gfxdraw;
- фигуры должны быть узнаваемы при размере клетки от 48 до 110 px;
- добавь функцию render_gallery(size) или аналогичную для показа всех фигур на экране меню/правил;
- кэш не должен расти бесконечно: ключ (тип, цвет, размер).

5. Виджеты
В chess/ui/widgets.py реализуй переиспользуемые элементы:
- Button(text, callback, enabled=True) с hover/active/disabled;
- Toggle(label, value, callback);
- RadioGroup(options, selected, callback) для размера доски и числа порталов;
- AbilityCard(ability_type, title, short_description, selected, enabled, callback) с местом под векторную иконку;
- Tooltip(text) или механизм отложенной подсказки;
- Modal / ConfirmDialog с кнопками;
- ScrollableText для экрана правил;
- вспомогательная функция draw_panel.
Все виджеты должны корректно работать при ресайзе окна.

6. Главное меню
MenuScene:
- крупный заголовок «Advanced Chess»;
- подзаголовок «Продвинутые шахматы»;
- кнопки «Играть», «Правила», «Выход»;
- галерея всех шести фигур обоих цветов (для проверки отрисовки);
- аккуратный фон, без внешних ассетов;
- клавиша Esc в меню не должна закрывать игру без подтверждения; кнопка «Выход» закрывает.

7. Экран настройки партии
SetupScene:
- dataclass SetupConfig: board_size (6/8/10), portal_count (0..3), abilities_enabled (bool), white_ability (BlessingType | None), black_ability (BlessingType | None);
- выбор размера доски: 6x6, 8x8, 10x10;
- выбор числа порталов: 0, 1, 2, 3;
- переключатель «Способности короля»;
- если способности включены — два блока карточек: «Белые» и «Чёрные», по пять способностей в каждом;
- карточки: щит (неуязвимость), x2 (двойной ход), возрождение, снежинка (заморозка), призрак (проход сквозь фигуры);
- выбранная карточка визуально выделена;
- обе стороны могут выбрать одну и ту же способность;
- при выключенных способностях карточки неактивны/скрыты;
- кнопка «Начать партию» неактивна, если способности включены и хотя бы одна сторона не выбрала способность;
- кнопка «Назад» возвращает в меню;
- справа или снизу — превью доски выбранного размера с координатами (пустая доска, без фигур);
- все тексты на русском;
- подсказки к способностям при наведении.

Определи BlessingType в chess/core/pieces.py или отдельном чистом модуле. Если создаёшь отдельный модуль, он не должен импортировать pygame.

8. Заглушка игрового экрана
GameScene:
- принимает SetupConfig;
- рисует доску выбранного размера с координатами;
- показывает панель: размер доски, число порталов, включены ли способности, выбранные способности;
- показывает заметный текст «Игровая логика будет добавлена на этапе 2»;
- кнопки «Назад в настройки» и «В меню»;
- не содержит игровой логики и не расставляет фигуры.

9. Заглушка экрана правил
RulesScene:
- прокручиваемый текст с разделами: «Размеры доски», «Порталы», «Благословения», «Управление»;
- на этом этапе достаточно краткого содержания; полный текст — этап 6;
- кнопка «Назад».

10. Тесты
tests/test_ui_smoke.py:
- установить SDL_VIDEODRIVER=dummy до импорта pygame;
- создать App/сцены, вызвать отрисовку одного кадра для меню, настройки, заглушки игры и правил;
- проверить, что render_piece возвращает Surface для всех типов и цветов;
- проверить валидацию SetupConfig: при включённых способностях без выбора кнопка старта недоступна.
Тесты не должны требовать реального дисплея.

11. README
README.md:
- описание проекта;
- установка: python -m venv, pip install -r requirements.txt;
- запуск: python main.py;
- управление;
- структура проекта;
- статус этапов;
- примечание, что графика векторная и внешних ассетов нет.

КРИТЕРИИ ГОТОВНОСТИ
- python main.py запускает приложение без ошибок.
- Работает навигация: меню -> настройка -> заглушка игры -> назад; меню -> правила -> назад.
- Все элементы настройки кликабельны и сохраняют состояние.
- Кнопка «Начать партию» корректно блокируется при неполном выборе способностей.
- Векторные фигуры обоих цветов видны в галерее и выглядят узнаваемо.
- Доска 6x6, 8x8 и 10x10 корректно масштабируется в превью.
- Русский текст отображается без «квадратиков».
- В chess/core нет импортов pygame.
- pytest проходит.
- README заполнен.

ПРОВЕРКА ПЕРЕД СДАЧЕЙ
- Запусти pytest.
- Запусти приложение вручную или через smoke-тест с dummy-драйвером.
- Проверь, что нет внешних ассетов.
- Проверь, что не реализованы механики следующих этапов.
